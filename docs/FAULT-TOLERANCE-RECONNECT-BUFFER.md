# 客户端重连位置缓冲

## 改动

H5 实时位置在断线时保留最新一条样本；Socket.IO 重新 `live:ready` 后：

- 只补发最新位置；
- 使用新的 `sampleId` 和 `sampledAt`，避免恢复水印误判为重复；
- 超过 **30 秒**的样本不补发（与服务端抓捕 30 秒新鲜度窗口一致）；
- 暂停、退出、隐藏、切换场次后不补发。

## 目的

cold/reconnect 压测中约 6.7% 的错误主要是客户端重连期间没有 ready，服务端并非写失败。该改动改善真实 H5 的网络切换体验，不改变服务端协议。

## 验证

- `pnpm test`：75 通过 / 11 跳过 / 0 失败
- `pnpm build`：通过

## 注意

压测器 `tests/load/clients.mjs` 是独立实现，不使用这段 H5 逻辑，所以该改动不会改变既有压测错误率；它针对真实浏览器重连。
